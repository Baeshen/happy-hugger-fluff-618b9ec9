# تنظيم الكثافة البصرية عبر تبويبات

الهدف: تقسيم كل شاشة مزدحمة إلى تبويبات (Tabs) تحمل نفس المحتوى الحالي بدون أي تغيير في المنطق أو قواعد البيانات — فقط إعادة تنظيم بصرية.

## النطاق والتبويبات المقترحة

### 1) `/dashboard` — لوحة التحكم
موجود بها Tabs مسبقًا (نظرة عامة / الرسوم / الحجوزات / النشاط). التحسينات:
- توحيد ترتيب البطاقات KPI أعلى تبويب "نظرة عامة" فقط، بدل تكرارها
- نقل شريط الفروع (Branch filter) إلى الترويسة الثابتة فوق التبويبات

### 2) `/patients/:id` — ملف المريض
موجود بها Tabs بالفعل (24 عنصر TabsTrigger). التحسينات:
- تجميع التبويبات في 5 مجموعات بدل قائمة طويلة:
  - **بيانات**: نظرة عامة + بيانات الاتصال
  - **سريري**: الحساسية + الأدوية + التاريخ المرضي + العمليات
  - **زيارات**: الزيارات + الملاحظات
  - **مرفقات**: الملفات + التقارير
  - **إدارة**: التنبيهات + الإعدادات
- نقل زر QR وشارة الحساسية الحرجة إلى ترويسة ثابتة فوق التبويبات

### 3) `/patients` — إدارة المرضى
لا يحوي تبويبات حاليًا. إضافة:
- **قائمة المرضى**: الفلاتر + الجدول (الافتراضي)
- **إضافة جديد**: نموذج الإنشاء (بدل الـ Dialog المنبثق) — يبقى الـ Dialog كخيار سريع من زر الترويسة
- **إحصائيات سريعة**: عدد المرضى / حسب الفرع / الجنس (بطاقات مختصرة تربط لـ `/patients-analytics`)

### 4) التحليلات والتقارير — 4 شاشات
دمج بصري تحت مسار موحد باستخدام تبويبات مشتركة في كل صفحة (شريط تنقل عرضي بين الشاشات الأربع في أعلى كل صفحة)، ثم تبويبات داخلية:

- **`/patients-analytics`** (الأكبر — 2137 سطر):
  - نظرة عامة (KPI + التوزيعات: الحالات/الجنس/الأعمار/الفرع/الوسوم)
  - الاتجاهات (تسجيلات يومية + تغييرات حالة)
  - الملخّص الذكي (ملخّص + إجراءات مقترحة)
  - أحداث الانتقالات (الأخير + الجدول التفصيلي)

- **`/reports`**: تبويبات حسب نوع التقرير (المرضى / الحجوزات / الأدوية / التقييمات)

- **`/transitions-stats`**: يحتوي تبويبات بالفعل — إبقاؤها مع توحيد نمط الترويسة

- **`/transition-alerts`**: تبويبات جديدة:
  - القواعد النشطة
  - السجل الزمني للتنبيهات
  - الإعدادات (الفلاتر + إنشاء قاعدة)

## قواعد التنفيذ

- استخدام مكوّن `Tabs` من `@/components/ui/tabs` الموجود مسبقًا
- الحفاظ على تخطيط الترويسة المتجاوب: `grid-cols-[minmax(0,1fr)_auto] sm:flex` مع `truncate` و`shrink-0`
- `TabsList` بشبكة على الجوّال: `grid-cols-2 sm:grid-cols-4 sm:inline-flex`
- عدم تغيير أي منطق: نفس الـ queries والـ mutations وأسماء الحقول والصلاحيات
- الحفاظ على `?tab=` في الـ URL عبر `useSearch` (اختياري لكل صفحة) لدعم مشاركة الروابط والعودة بالمتصفح

## ملاحظات

- لن يتم إنشاء ملفات مسارات جديدة أو تعديل قاعدة البيانات
- تحذيرات الأمان الظاهرة في لوحة "المزيد" خارج نطاق هذا الطلب — سنعالجها في مهمة منفصلة عند طلبها
