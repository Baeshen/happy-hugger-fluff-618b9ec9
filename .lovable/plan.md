
سأبني منصة **مجمع باعشن الطبي** على مراحل. المشروع كبير، لذا سنبدأ بالمرحلة الأولى (الواجهة العامة + قاعدة البيانات + الحجز/طلب الدواء)، ثم لوحة التحكم في مرحلة تالية.

## المرحلة 1 — الأساس والواجهة العامة (سنبنيها الآن)

### الإعداد
- تفعيل **Lovable Cloud** (قاعدة البيانات، المصادقة، تخزين صور الوصفات).
- إعداد **RTL كافتراضي** + مبدّل لغة عربي/إنجليزي مع حفظ الاختيار.
- الهوية: تركوازي طبي `#0E7C7B` / `#14B8A6`، خط Cairo للعربي و Inter للإنجليزي، تصميم نظيف يشبه مواقع المستشفيات الحديثة.

### الصفحات العامة
1. **الرئيسية** — Hero «رعايتك تبدأ هنا» + زرا CTA (احجز موعدًا / اطلب دواء)، شريط تواصل سريع، شبكة التخصصات، لماذا باعشن، أطباء مميزون، Footer كامل بالعنوان والخريطة والسوشيال.
2. **التخصصات** — شبكة بطاقات + صفحة تفصيل لكل تخصص.
3. **الأطباء** — بحث/فلترة حسب التخصص + بطاقات أطباء.
4. **حجز موعد** — تدفق متعدد الخطوات (تخصص → طبيب → تاريخ ووقت → بيانات المريض → تأكيد).
5. **طلب توصيل دواء** — رفع صورة الوصفة أو كتابة القائمة + بيانات التوصيل.
6. **من نحن / تواصل / الأسئلة الشائعة**.

### قاعدة البيانات (Supabase)
جداول: `specialties`, `doctors`, `availability`, `appointments`, `medicine_orders`, `profiles` + جدول أدوار منفصل `user_roles` (admin / reception / pharmacy) مع دالة `has_role` آمنة.
- سياسات RLS: قراءة عامة للأطباء/التخصصات، إدراج عام للحجوزات وطلبات الأدوية، القراءة/التحديث للموظفين حسب الدور.
- Storage bucket لصور الوصفات.
- Seed data: بيانات المجمع + التخصصات المبدئية.

## المرحلة 2 (لاحقًا، بعد اعتمادك للمرحلة 1)
- لوحة تحكم `/admin` (تسجيل دخول، إحصائيات، إدارة الحجوزات وطلبات الأدوية، CRUD للأطباء/التخصصات/الفترات، إدارة المستخدمين والأدوار).
